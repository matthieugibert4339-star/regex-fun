🧠 Mémo

Les indispensables

À relire avant une session
1. Les classes\d chiffre • \w lettre/chiffre/_ • \s espace
\d\d → deux chiffres
2. Les crochets[abc] a/b/c • [a-z] minuscule • [^0-9] tout sauf chiffre
[A-Z] → une majuscule
3. Les quantificateurs+ 1 ou + • * 0 ou + • ? 0 ou 1 • {3} exactement 3
\d{5} → cinq chiffres
4. Les ancres^ début • $ fin • \b frontière de mot
^\d{5}$ → uniquement 5 chiffres
5. Groupes / choix( ) regroupe • | signifie « ou »
^(oui|non)$
6. ÉchapperPour chercher un symbole spécial littéralement, ajoute \ devant.
\.com → « .com »
7. Méthode express1) définir le format • 2) découper • 3) choisir les classes • 4) quantifier • 5) ancrer • 6) tester
Toujours tester au moins un cas qui doit passer et un qui doit échouer.
